# Deploy

Repozytorium nie zawiera poświadczeń ani automatycznego wdrożenia do tenantów klienta. Ten katalog jest miejscem na artefakty wdrożeniowe Fabric po decyzji o środowisku: definicje workspace, Data Pipeline, skróty OneLake, import KQL i parametry aplikacji.

Minimalna ścieżka wdrożenia jest opisana w `..\SETUP_FABRIC.md`. W produkcji należy użyć Managed Identity, Key Vault, Purview i RLS; nie należy wpisywać sekretów do plików repozytorium.
