# Deployment notes

Ten katalog jest miejscem na artefakty wdrożeniowe Fabric. W demo nie ma automatycznego wdrożenia infrastruktury, bo scenariusz koncentruje się na danych, modelu i narracji decyzyjnej.

Minimalna kolejność wdrożenia jest opisana w `..\SETUP_FABRIC.md`.

Nie zapisuj tutaj poświadczeń, connection stringów ani eksportów zawierających dane klienta.
