# Specyfikacja raportu Power BI

## 1. Executive overview

Karty: popyt odbiorców, paliwo zaoszczędzone, emisje zaoszczędzone, redukcja strat, residual bilansu. Wniosek strony: optymalizacja nie narusza komfortu i zamyka bilans.

## 2. Prognoza zapotrzebowania

Wykres actual vs forecast vs baseline dla D-2 … D+5. Karty MAE/RMSE/MAPE. Wniosek: model z bezwładnością cieplną istotnie poprawia baseline temperaturowy.

## 3. Plan pracy źródeł

Stacked area: produkcja według źródła. Linie: cena energii elektrycznej, popyt, straty. Wniosek: kogeneracja jest oceniana razem z ceną energii elektrycznej.

## 4. Magazyn ciepła

SOC, charge/discharge, minimalny SOC, maksymalny SOC. Wniosek: magazyn pracuje wyprzedzająco, nie reaktywnie.

## 5. Sieć i temperatura

Temperatura zasilania baseline vs optimized, straty sieci, temperatura zewnętrzna. Wniosek: obniżenie temperatury zmniejsza straty tylko tam, gdzie nie narusza komfortu.

## 6. Ślad decyzji

Tabela rekomendacji, status akceptacji, dyżurny, uzasadnienie, timestamp. Wniosek: AI doradza, człowiek akceptuje.
