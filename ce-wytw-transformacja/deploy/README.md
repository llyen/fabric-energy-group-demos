# Deploy

Katalog na artefakty wdrożeniowe Fabric używane poza lokalnym demo: definicje pipeline, parametry workspace, eksport modelu semantycznego i skrypty automatyzujące publikację.

W tym repozytorium nie ma poświadczeń ani plików środowiskowych. Konfigurację należy tworzyć na podstawie `config.example.json` i przechowywać poza repozytorium albo w bezpiecznym magazynie sekretów.

Minimalna ścieżka wdrożenia jest opisana w `../SETUP_FABRIC.md`.
