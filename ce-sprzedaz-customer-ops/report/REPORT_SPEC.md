# Specyfikacja raportu Power BI

## 1. Szczyt kontaktowy
KPI: kontakty, szczyt dzienny, średnia dzienna, udział D-14…D+14. Wizuale: linia dzienna, kanały, eskalacje.

## 2. Root cause
Pareto przyczyn, udział top 3, średni czas obsługi i repeat rate per przyczyna. Wniosek strony: mała liczba przyczyn generuje większość ruchu.

## 3. Sprzedawca vs OSD
Macierz przyczyn: owner sprzedawca / front-door sprzedawca / owner OSD. Wniosek: klient nie widzi granicy, model i proces muszą ją widzieć.

## 4. AI w obsłudze
Metryki klasyfikacji vs baseline, confusion matrix, kolejka niskiej pewności.

## 5. Predykcja kontaktu
Lift po decylach ryzyka, czynniki ryzyka, lista faktur do działań uprzedzających.

## 6. Domknięcie pętli
Symulacja prewencji, oszczędzone godziny obsługi, uniknięte powtórki, status działań write-back.
